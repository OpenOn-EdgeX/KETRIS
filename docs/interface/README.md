# KRAKEN 3기관 인터페이스 규격 (Exp_81, 2026-08-11)

> **이 문서군은 KETI가 제안하는 규격이지 확정이 아니다.** 각 기관의 실제 구현 제약에
> 따라 조정 여지가 있다. 각 규격의 **"확인 필요"** 절이 협의 시 물어볼 항목이다.

KRAKEN 통합 시스템은 4개 기관이 맞물린다. KETI(우리)는 **시공간 분할 + 오버커밋 + 비대칭 제어**를
담당하고, 나머지 3기관의 경계면을 아래 규격으로 정의한다.

```
  하스퍼(HW)          KETI(자원분할)              고려대(스케줄/SLO)
  ─────────           ────────────                ──────────────
  capability JSON ──▶ 카탈로그 등재·광고          워크로드 유형·우선순위
  (A-1)               가용용량 API (A-2) ────────▶ 제출·라우팅
  회수 핸드셰이크 ◀──  비대칭 제어 자동전환  ◀──── 메타데이터 (A-3)
                          │
                          ▼ 메트릭·이벤트 (A-4)
                      오케스트로(관측/대시보드)
```

> **통합 문서**: 네 규격 + 검증 기록 + 협의 질문을 한자리에 모은 것은
> `reports/Exp_136_interface_document/report.md` (기관 협의 자리용).

| 규격 | 방향 | 파일 |
|---|---|---|
| A-1 물리 자원 명세 | 하스퍼 → KETI | `A1_hasper_capability.md` |
| A-2 가용 용량 조회 | KETI → 고려대 | `A2_keti_capacity_api.md` |
| A-3 워크로드 메타데이터 | 고려대 → KETI | `A3_korea_workload_metadata.md` |
| A-4 메트릭·이벤트 | KETI → 오케스트로 | `A4_orchestro_metrics_events.md` |

## 관통하는 설계 원칙

1. **논리 용량은 실측 기반이다.** LSU(Logical Slice Unit)는 레퍼런스 워크로드 실측으로만
   산출된다(현재 `resnet50_inference_fp16`, A6000=65LSU 교정). 미실측 장비는 **잠정값**으로
   등재되며 그 상태가 A-2 응답에 드러난다. 스펙에서 자동 산출하지 않는다.
2. **간섭은 겹침(Σpct)의 함수다.** Exp_78~80 실측: Σpct(=Σ요청LSU/물리LSU)≤100%는 공간분할이
   격리(무간섭), Σpct≥140%에서 실경합. A-2가 이 힌트를 싣는다.
3. **워크로드 역할은 선언 사항이지 요구 사항이 아니다.**
   Exp_131에서 CUPTI 주입으로 커널 관측이 열려 "연산을 많이 쓰는가"는 판정된다.
   그러나 (ㄱ) 판정에 실행 후 약 1초가 걸리고 그 전에는 정반대 답을 내며,
   (ㄴ) "응답 시간을 지켜줘야 하는가"는 관측이 알 수 없다.
   그래서 A-3 선언을 남기되 **고려대에 요구하지 않는다** — 없으면 관측 판정을
   **자원을 더 주는 방향으로만** 쓴다(계획, 미구현). 현재는 양쪽에 같은 방식을 적용한다.
