# KRAKEN 페어링 예측 의미론 — 정본 (Exp_48/49)

**정본 지위**: co-location 조합 특성 예측(분류 v2 공간 지표 기반)의 단일 정본.
구현 정본 = `controller/ratio/pair_predict.py` (decide_pair 의 보조 출력),
지표 산출 = `profiler/kernel_class_v2/`. 모든 서술은 실측 근거 각주를 갖는다.

**★용도 한계 (최우선 — Exp_39b 결론 보호)**: 페어링 예측은 **비율 결정자가
아니다**. co-location 이득의 원천은 봉투 완화(time_sharing.md §7)이며, 본 예측은
**배치(어느 페어를 같은 GPU 에) · 봉투 정책 선택의 보조 입력**이다. s/t/gate
결정에 일절 관여하지 않는다(test_18 이 회귀 감시).[^1]

---

## §1. 지표 (분류 v2 — 트레이스 후처리, 수집 증분 0)

| 지표 | 정의 | 물리 의미 |
|---|---|---|
| `device_fill` | 시간가중 min(blocks, maxBlk×SM)×wpb/(SM×max_warps) | 커널 **실행 중** 장치 워프 점유율 (공간) |
| `kernel_density` | Σ커널시간 / 벽시계 | 벽시계 중 커널이 도는 비율 (시간) — launch-bound 판별 |

occupancy 는 공식 구현(cuda_occupancy.h) — Exp_48 §Phase 0.[^2]

## §2. 규칙 — 곱(wall_fill) 단일 축 (Exp_56 개정)

이종 페어(v1 C×M, confidence HIGH)에서 M측이

```
공간 경합  ⇔  wall_fill = device_fill × kernel_density  ≥  0.41
```

미만이면 **이종 상보** — 공간이 비거나(fill 낮음) 시간이 비거나(launch-bound)
파트너가 들어갈 틈이 있다. wall_fill 은 "**벽시계 전체에서 SM 을 실제로 붙잡고
있는 비율**"이다.

**개정 경위(Exp_49 → Exp_56)**: Exp_49 는 2차원 AND(`fill>0.60 AND density≥0.5`)
였다. Exp_56 이 빈 구간에 새 케이스 4종을 넣자 AND 가 **2건 오판** —
densenet121(두 축 모두 임계 초과 → 경합 예측, 실측 OC 1.326 = 상보)과
convnext_tiny(fill 미달 → 상보 예측, 실측 1.082 = 경합). 두 축을 각각 자르면
"곱은 작은데 둘 다 아슬하게 넘는" 경우를 구분하지 못한다. 곱 기준으로 바꾸면
9케이스 중 오판이 **2건 → 1건**으로 줄고 서열이 거의 단조가 된다.[^3]

**실측 근거 — 16케이스** (전부 bert 파트너 MPS 50/50 ×3회, 사전 예측 고정 후 검증.
◆ = Exp_56 신규, ● = Exp_58 신규, ■ = Exp_60 신규(창 경계 밖)):[^3]

**임계 도출**: convnext 계열(CM 가드 담당)을 제외하면 상보군 최대 0.398(decode)와

실측 극값 사이에서만 잡았고 케이스 맞춤 조정은 없다(overfit 금지 원칙).[^4]

★**convnext 오판의 원인 규명과 CM MIXED 보수 가드 (Exp_58)**: Exp_56 이 남긴
오판 1건(convnext_tiny)의 근원은 파트너 간섭이 아니라 **자기 유지율**이다 —
페어 OC 를 "자기 유지율 합 − 상호 간섭"으로 분해하면 bert 페어의 상호 간섭은
0.31~0.36 으로 균질(regnet 만 0.08)하고, OC 차이는 SM 절반(단독, 파트너 없음)
에서의 유지율 ret50 이 결정한다: 같은 wall_fill 대(0.35~0.37)에서 densenet121
ret50 **1.003** vs convnext_tiny **0.716**. 기전: convnext 는 MEMORY 상반
(LayerNorm/GELU 등 elementwise, fill≈1.0, 시간 50.4%)과 COMPUTE 하반(smem
64~73KB GEMM, fill≈0.17, 시간 48.7%)의 **이중구조**라 평균 fill(0.584)이 희석돼
wall_fill 이 s-절단 민감도를 담지 못한다. convnext_small/base 페어 실측
(1.085/1.079, ret50 0.726/0.721)으로 **계열 전체가 같은 패턴**임을 확인 →
`cm_ratio ∈ [0.45, 0.66]`(MIXED 경계) AND wall_fill<임계 → **보수 경합 취급**
가드를 채택했다(창 도출: 하단 = 상보-정답 최대 cm 0.414 와 오판 최소 0.491 의
중간점, 상단 = 오판 최대 0.597 과 최근접 상위 케이스 0.727(decode b=2, 페어
미실측이라 잠정)의 중간점. 정답 12건 중 창 안 0건 = 기존 판정 무영향).
cm 부재 시 가드 미발동(하위호환). 대역폭 경합 가설은 부분 근거만 확보
(convnext×decode 상호 간섭 0.476 로 최대 — 양쪽 모두 대역폭 수요) —
CUPTI Metrics 고비용 경로는 **불채택**(가드로 실용 해소, Exp_58 §1).[^6]

**★CM 창 확정 (Exp_60) — 잠정 태그 해제**: Exp_58 이 상단 0.66 을 "이웃
페어 미실측"이라 잠정으로 남겼다. Exp_60 이 경계 **밖** 3케이스를 실측해 판정했다:[^7]

- **상단 타당**: decode b=2(cm 0.727, 창 밖) → 가드 미발동 → wall_fill 규칙만으로
  상보 예측, 실측 **1.198**(상보 경계 상단) — 적중.
- **하단 타당**: mnasnet1_0(cm 0.415, 창 바로 아래) → 상보 예측, 실측 **1.328** — 적중.
- ★**새 예외 roberta-base**(cm 0.792, wall 0.273): 창 밖이라 상보 예측인데 실측
  **1.097**. 그런데 **창을 넓히는 것으로는 고칠 수 없다** — 창 상단을 0.8 까지
  올리면 decode b=2(cm 0.727, 실측 상보 1.198)를 경합으로 오판하기 때문이다.
  **cm 축 확장 불가가 반례로 증명**됐으므로 창은 [0.45, 0.66] 그대로 **확정**하고
  roberta 를 명시적 예외로 기록한다(test_18 이 한계를 봉인).

**★★ret50 축 발견 (Exp_60, 규칙 미채택·후속 과제)**: roberta 예외의 원인은
cm 이 아니라 **자기 유지율**이다(ret50 0.668 — Exp_58 이 convnext 오판에서 찾은
그 차원). 11케이스 전수 대조에서 상관이 압도적이다:[^7]

| 지표 | OC 와의 상관 | 분리력 |
|---|---|---|
| **ret50** (= sps(pct50 단독)/sps(pct99 단독)) | **+0.855** | 경합군 최대 0.777 ↔ 상보군 최소 0.881 — **완전 분리**(중간점 0.83), 11/11 |
| wall_fill | −0.529 | 부분 |
| cm_ratio | −0.507 | 부분 |

즉 "파트너와의 간섭"보다 "**SM 절반에서 혼자 얼마나 버티는가**"가 페어 OC 를
결정한다(Exp_58 의 간섭 균질성 0.31~0.36 관찰과 정합). 다만 ret50 은 트레이스
후처리로 얻는 지표가 아니라 **단독 실측 2회**(pct99/pct50)가 필요해 비용이 다르고,
검증도 bert 파트너 11케이스에 한정된다. 따라서 **규칙으로 채택하지 않고**
지표·근거로만 기록한다 — 채택 판단(비용·파트너 일반성)은 후속 실험 몫이다.

## §3. 출력·앵커·가드

- 카테고리: `hetero_complementary` / `hetero_space_contended` / `homo_c` / `homo_m`.
  **신뢰 산출물은 카테고리**다. `expected_oc` 는 참고 앵커(Exp_15/17 실측 대표값 —
  이종 1.205·동종C 0.945·동종M 1.152·경합=self_pair_oc 또는 보수 하한 0.945)이며
  **수치 이전성은 조합 의존**: 신규 상보 조합 실측 1.462~1.591 로 앵커를 상회
  (Exp_17 "이득 크기는 조합 의존" 재확인). 경합 예측 정밀도는 높음(1.083 예측 vs
  1.087 실측).[^5]
- 가드(전부 사유 기록): 지표 부재 → available=False = **v1 단독 동작(기본값,
  기존 무변경)** / density 부재 + fill 높음 → 보수 취급(경합 가정 — OC 과소추정
  방향이 배치 안전) / 2-tenant 아님·UNCERTAIN·confidence≠HIGH·범위 밖 → 보류.
- 지표 공급: 현 단계 = 정적 프로파일(오프라인 trace → classify_v2, (a) 경로).
  온라인 사이드카((b), Exp_48 Phase 4 91k kernels/s)는 후속.
